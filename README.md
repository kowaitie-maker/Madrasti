# مدرستي

مكتبة الكتب المدرسية ونماذج الاختبارات للمنهج الكويتي، للصفوف: السادس والسابع والثامن والعاشر.
المصدر الأصلي هو مجلد «مدرستي» على قوقل درايف، ونُقلت الملفات هنا حتى يصل إليها برنامج إعداد الاختبارات مباشرة عبر روابط ثابتة.

## الفهرس

كل ما يحتاجه البرنامج موجود في ملف الفهرس:

```
https://raw.githubusercontent.com/kowaitie-maker/Madrasti/main/index.json
```

يحتوي الفهرس لكل صف ومادة على:

| الحقل | المعنى |
|---|---|
| `books` | الكتب المدرسية للمادة |
| `exams` | نماذج الاختبارات، مرقمة |
| `resources` | ملفات مساعدة مثل الثروة اللغوية والأحاديث المقررة |
| `url` | الرابط المباشر لتحميل الملف |
| `pdf_pages` | عدد صفحات الملف |
| `parts` | بداية ونهاية القسم الأول والثاني بأرقام صفحات الملف |
| `page_map` | تحويل رقم الصفحة المطبوع في الكتاب إلى رقم صفحة الملف |
| `numbering` | نوع الترقيم: متصل بين القسمين، أو يبدأ من جديد، أو قسم واحد |

## تحويل رقم الصفحة المطبوع إلى صفحة الملف

1. حدد الكتاب ثم القسم المطلوب.
2. في خريطة الصفحات ابحث عن السطر الخاص بالقسم نفسه الذي يقع الرقم المطبوع ضمن مداه.
3. رقم صفحة الملف = الرقم المطبوع + الإزاحة الموجودة في ذلك السطر.

مثال: كتاب لغتي العربية للصف السادس يبدأ ترقيمه من جديد في القسم الثاني، لذلك صفحة ٥٨ من القسم الثاني هي صفحة الملف ٢٠٠، بينما صفحة ٥٨ من القسم الأول هي صفحة الملف ٥٩.

## هيكل المجلدات

```
index.json
Grade-6/

Grade-7/
Grade-8/
```

أسماء الملفات بالإنجليزية حتى تعمل الروابط دون مشاكل، والاسم العربي الأصلي محفوظ في الفهرس لكل ملف.

## الملفات الكبيرة

جيت هب لا يقبل ملفاً أكبر من ١٠٠ ميجابايت، لذلك قُسّم كل ملف أكبر من هذا الحد إلى أجزاء بجودته الأصلية دون ضغط.
اسم كل جزء يوضح مدى صفحاته، مثل `Science-pdfpages-001-121.pdf`، والفهرس يذكر الأجزاء ومدى صفحات كل جزء.
كتاب العلوم للصف السادس قُسّم بحيث يبدأ القسم الثاني في ملف مستقل.

## تحديث المكتبة

عند إضافة ملفات جديدة إلى مجلد «مدرستي» على قوقل درايف:

1. يُحدَّث ملف `tools/manifest.json` بالملفات الجديدة.
2. تنقل خوادم جيت هب الملفات تلقائياً من درايف إلى المجلد الصحيح.
3. يُحلَّل ترقيم صفحات الكتب الجديدة ويُعاد بناء `index.json`.
